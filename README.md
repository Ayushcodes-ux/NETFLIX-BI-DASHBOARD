# 🎬 Netflix BI Dashboard

## 📌 Overview
This project analyzes Netflix's content library using **Power BI** to uncover key trends 
in movies, TV shows, genres, and country-wise content distribution. The dashboard provides 
an interactive way to explore Netflix's catalog and understand content patterns over time.

## 🎯 Objectives
- Track **Total Movies** vs **Total Shows** on the platform
- Analyze **content trends over the years** (release year / addition year)
- Explore **genre-wise distribution** of content
- Compare **country-wise content production** on Netflix
- Identify top contributing countries and popular genres

## 📊 Key KPIs
| KPI | Description |
|-----|-------------|
| 🎥 Total Movies | Total number of movies available on Netflix |
| 📺 Total Shows | Total number of TV shows available on Netflix |
| 🌍 Total Countries |Total numbers of Countries producing the most content |
| 🎭 Top Genres | Most common genres across the catalog |
| 📅 Yearly Trend | Growth of content added over the years |

## 🛠️ Tools & Technologies
- **Power BI** — Dashboard design and data visualization
- **Excel** — Data cleaning and preprocessing
